## Perubahan dan atribusi

File menggunakan rendition 768 × 512 yang disediakan sumber. Tidak ada retouch, recoloring, atau crop lokal pada file ini. Mark sumber `UGA1436121` dipertahankan. Preview chat dapat memakai crop visual untuk memenuhi bubble; tampilan tersebut tidak mengubah file tersimpan.

Kredit terdaftar dalam `lib/site-config.ts` dan dirender di footer dengan tautan sumber/lisensi serta keterangan “thumbnail diperkecil; tampilan preview dipotong”. Kredit yang relevan: “Foto oleh Clemson University - USDA Cooperative Extension Slide Series, Bugwood.org — CC BY 3.0”.

## Batas penggunaan dalam demo

Foto adalah lampiran contoh pada [demo terpandu](iphone-demo.md). Ini bukan foto dari pengguna/pilot AgriSense, hasil analisis AI, atau bukti diagnosis layanan langsung. Transcript hanya menampilkan balasan klarifikasi contoh.

Penggunaan foto tidak menyatakan dukungan resmi dari Clemson University, USDA, Bugwood.org, atau Wikimedia kepada AgriSense. Sumber/lisensi aset lain ada di [manifest aset](asset-manifest.md).
